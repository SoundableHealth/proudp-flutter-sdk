# SoundableProudpLib (CocoaPods only)

SoundableProudpLib is distributed only as a Swift package, so these files are a copy of
https://github.com/SoundableHealth/SoundableProudpLib/tree/12e9b71ce1f55819869b2602a83602383339f694/Sources/SoundableProudpLib
and are compiled into the plugin only when the app uses CocoaPods.

With Swift Package Manager the package is resolved from GitHub (see `soundable_proudp/Package.swift`).
When updating the revision in `Package.swift`, copy the files again from the same revision.
